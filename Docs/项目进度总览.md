**接手时最容易犯的三个错**（血泪）：

1. 在 `Core/` 里 `using UnityEngine` —— 立刻破坏"逻辑能搬服务器"的地基
2. 在 UI 里重写"能不能放下"的判断 —— 空间规则只能有一份，就是 `ItemContainer`
3. 新加组件字段不做零值兜底 —— 场景里已挂的组件反序列化时**不执行字段初始化器**，`bool = true` 会读成 `false`、`LayerMask` 会读成 `Nothing`（坑 #12 / #17 / #18，已踩四次）
