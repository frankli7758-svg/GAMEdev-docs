## A 组 ·「打开容器不搜索」的两个主因（6 条）

| # | 操作 | 期望结果 | 过 |
|---|---|---|---|
| A-1 | **按住 W 一直不放**，同时走到箱子前按 F | 容器打开，**有放大镜在晃、物品开始被搜出来**（不该出现"界面开了但什么也不动"） | ☐ |
| A-2 | 站在三只箱子中间按 F 打开其中一只 | **只有打开的那只**在搜。然后关掉，去开另外两只 → **它们各自都还有放大镜**（不该是"已经全搜完了"） | ☐ |
| A-3 | 打开箱子，把一件物品搜出来后，鼠标指着**背包里**的物品按 F | 物品**回到右边容器**，并且**不是灰块**（不该需要重新搜） | ☐ |
| A-4 | 先把背包塞到只剩**一条竖缝**，再从容器拖一件 **4×1** 的物品到那条缝附近 | 物品**自动转成 1×4** 并放下；顶部提示出现「已自动转向」 | ☐ |
| A-5 | 拖一件**大件**（4×1 或 2×4）到网格**上边缘 / 左边缘**附近 | 预览框自动往里贴一格并变绿，**不是整块变红** | ☐ |
| A-6 | 搜索进行中，让僵尸咬你一口 | 弹 Toast「搜索已中断（受到伤害（X））　按 F 继续」；**鼠标不指任何物品**时按 F 能续上（放大镜重新出现） | ☐ |

> A-1 / A-2 是**同一天报的同一个现象的两个独立成因**，必须分开测：
> A-1 验"中断判定有没有绕过交互仲裁"，A-2 验"多只箱子会不会一起后台开搜"。

## B 组 · 光晕形状与遗留（4 条）

| # | 操作 | 期望结果 | 过 |
|---|---|---|---|
| B-1 | 搜出一件 **2×4（太阳能板）** 或 **1×4（古董滑膛枪）** | 光晕是**长条形**，跟住物品轮廓，不是正方形 | ☐ |
| B-2 | 搜出一件 **1×1** 的物品（废料 / 弹药） | 观感和改之前**一致**：正方形，起始略藏在物品下方 | ☐ |
| B-3 | 揭晓动画那 **0.18 秒内立刻按 F** 把东西捡进背包 | 光晕**跟着消失**，不能留在格子里 | ☐ |
| B-4 | 连按 F 把一箱捡空 → 关界面（Tab / Esc） | 画面里**不残留任何光斑** | ☐ |

> B-3 是今天修的那个 bug（光晕是兄弟节点，池化回收时不跟着关）。
> 想稳定复现：**搜出来的一瞬间就狂按 F**，捡走得越快越容易撞上。

## 失败了怎么反馈

一句"不行"我很难定位，有这三样最好：

1. **哪一条**（编号，如 A-2）
2. **实际看到什么**（越具体越好："界面开了，但格子里全是灰块且没有放大镜"）
3. **Console 里这几行**：`grep` 关键词 `[搜索]` / `[库存]` / `[容器]`

如果是崩溃或卡死，再补一句"当时在按什么键"。
