## 3. 布局契约（用户明确要求"位置不要写死"）

1. **所有尺寸/颜色只来自 `MenuTheme`**（`[Serializable]`，主菜单对象上可在 Inspector 直接改）。
   页面脚本里**不出现魔法像素**，只有相对关系。
2. 区域一律用**拉伸锚点 + 四边偏移**（`offsetMin/offsetMax`）表达"离父节点各边多远"。
   不用 `sizeDelta` 直接写宽高（拉伸锚点下 `sizeDelta` 语义是"相对父节点的增减"，极易算错，
   曾经写出负尺寸导致节点完全不渲染）。
3. 画布用 `CanvasScaler.ScaleWithScreenSize`（参考 1920×1080、match 0.5），
   所以 `MenuTheme` 里的像素值在任何分辨率下都是**同一个比例**。
4. 拿到示例图后要改的东西：`MenuTheme` 的字段 + 各页面内部的相对位置。
   **逻辑（按钮回调、搬运、存档）不用动。**

## 4. 营地为什么需要"装备架"

仓库页中间那两栏是**真网格**（要读格子、要拖物品），需要一个真实的 `CarryGroup`。
但营地里没有 Player。所以 `MainMenuScreen` 会造一个只挂 `PlayerInventory` 的离线对象
（`CampInventory`）：

- 它同样走 `EnsureBuilt` → **从存档恢复 loadout**；
- 营地不属于战局（`RaidDirector.Running == false`），自动保存会**把 loadout 写回**；
- 进图前 `MenuFlow.EnterRaid` 还会 `SaveNow` 一次，保证战局拿到的是最新装备。

## 5. 设置：哪些真生效，哪些灰掉

**硬规矩**（用户选的 2A 策略）：**只做真能生效的开关**；做不到的显示为不可用并写明原因。
假开关比没有更糟 —— 玩家以为调了，实际没变。

| 项 | 状态 | 说明 |
|---|---|---|
| 显示模式 / 分辨率 / 垂直同步 / 最大帧率 | ✅ | `Screen` / `QualitySettings` / `Application.targetFrameRate` |
| 画面质量 | ✅ | 只有 2 档（Mobile / PC），来自 `QualitySettings.names` |
| 纹理质量 | ✅ | `QualitySettings.globalTextureMipmapLimit` |
| 主音量 | ✅ | `AudioListener.volume` |
| 改键（开火 / 瞄准 / 换弹 / 交互 / 背包 / 信号枪） | ✅ | 复用 `GameInput.StartRebind`，显示名走新增的 `GetBindingDisplay` |
| 渲染分辨率 / 阴影质量 | ❌ | 要改 URP 资产（`PC_RPAsset`），运行时会**改脏资产文件** |
| 后期效果 / 动态模糊 | ❌ | 项目里没有 Volume / 后处理组件，没有对象可调 |
| 音效 / 音乐音量 | ❌ | 没有 `AudioMixer`，无法分总线 |
| 瞄准方式 / 冲刺方式 | ❌ | 要改输入层（`AimHeld` 直接读物理键） |
| 伤害数字 / 镜头晃动 / HUD 缩放 / 准星样式 / 字幕大小 | ❌ | 缺对应的系统或统一入口 |
| 语言：英语 | ❌ | 无本地化系统（文案全硬编码） |
| 辅助功能四项 | ❌ | 屏幕震动、连点、UI 主题、色盲配色都还没有 |

**设置存在 `PlayerPrefs`（键前缀 `zx.settings.`），不进存档文件。** 理由：

- 设置是"这台机器的偏好"，不是游戏进度；
- 存档有 `schemaVersion` 校验，**升版本会让玩家现有存档直接读不出来**
  （`SaveService` 对"版本低于程序且无迁移器"是拒绝读取）——
  为一个音量开关冒"老档打不开"的风险不值得；
- 键位改绑本来就已经在 `PlayerPrefs` 里（`zx.input.*`），放一起反而一致。

编辑器里**启动时不会套用分辨率**（`#if !UNITY_EDITOR`）：否则每次进 Play 都会把 Game 视图
改成存档里那档，很干扰调试；手动改设置时仍然立即生效。

## 9. 验收清单（手测）

**A. 能进能出**
1. 打开 `MainMenu` → Play → 看到营地页（顶栏有玩家名与资金）
2. 点「开始游戏」→ 进灰盒图，能正常行动/搜刮
3. 撤离成功 → 只有「返回主菜单」→ 点击回营地

**B. 仓库页**
4. 点左侧「仓库」→ 三栏出现：左（角色占位 + 3 武器槽）、中（背包 + 弹挂）、右（仓库）
5. 从仓库拖一件到背包空格 → 落到指定位置；拖动中按 R 能转向
6. 拖到只剩竖缝的位置 → **自动转向**放进去
7. 指着物品按 **F** → 仓库 ⇒ 身上 / 身上 ⇒ 仓库；右键同效
8. 回营地后再进图 → 刚搬进背包的东西**在局内背包里**

**C. 设置页**
9. 点「设置」→ 七个分组都能点开
10. 改显示模式 / 垂直同步 / 主音量 → 立即生效；退出 Play 再进 → 值还在
11. 改一个键（例如开火）→ 显示新键；游戏中按新键生效
12. 灰掉的项：有「—」和原因说明，点不动

**D. 结算面板**
13. 阵亡 → 面板出现，鼠标可用；「返回营地」回主菜单；「呼叫渡鸦救援」灰着
14. 撤离成功 → 面板只显示一个按钮

**E. 启动菜单**
15. `ZombieExtraction/启动/Play（灰盒测试场）` → 直接进战局，跳过菜单
