## 10:15 实机修 bug：仓库页右栏整块不可见（坑 #39）

**用户反馈**：首次 Play 主菜单 → 仓库页只看到背包，看不到仓库。

**根因**：`MenuPage.Region(...)` 的 `left/right` 是"向内缩进"语义（`offsetMin.x = left`、`offsetMax.x = -right`）。
右栏是**点锚点**（`anchorMin.x == anchorMax.x == 1`），水平宽度只由两者之差决定 → 传 `left = +560` 得 **−560 宽度**。
负尺寸 `RectTransform` 不报错、不渲染，且左边界在 host 外 560px（屏幕外）→ 整栏"根本不存在"。
左栏当时写 `right = -320` 负负得正，属于靠符号凑，掩盖了同族错误。

**修**：
- `MenuPage.SideColumn(name, parent, width, rightSide)` 新增：固定宽度、贴左/贴右、上下拉伸，宽度恒正。
- `StashPage.Build` 左右两栏改用 `SideColumn`；中栏仍 `Region`（真拉伸）。
- `BuildCarryColumn` 里 `host.GetChild(childCount-1)` 反查标题 → 改用 `MenuUi.Label` 返回值。

  `RectTransform`，`rect` 任一维 < −0.5 就 `LogError` 打节点路径（最多 8 条）。只查负值不查 0（空占位正常）。

## 10:47 修「[存档] 没有 ItemDatabase」假错误（坑 #40）

**现象**：进主菜单 Console 一条 LogError，栈 `SaveManager:Awake ← AddComponent ← EnsureExists ← MainMenuScreen:Awake`。

**根因**：`SaveManager.EnsureExists()` 建宿主走 `host.AddComponent<SaveManager>()`，`Awake` **同步**执行；
`MainMenuScreen` 必须等 AddComponent 返回后才能把 `ItemDatabase` 注入 → Awake 里 `EnsureLoaded()` 那一刻必然 null
（营地场景没有 `PlayerInventory` 可借）→ 报错 + 保持未加载；外面再调一次才成功。功能没错，错在顺序。

**修**：
- `SaveManager.Awake`：`if (database) EnsureLoaded();`（有引用才初始化）+ 新增 `Start()` 里 `if (!_loaded) EnsureLoaded();` 兜底。
- `MainMenuScreen.Awake`：`EnsureExists()` 返回后先 `if (Saves.database == null && database != null) Saves.database = database;` 再 `EnsureLoaded()`。

**通用规律（坑 #40）**：`EnsureExists()/AddComponent` 工厂 + `Awake` 读外部引用 = 必然踩。要么 Awake 自给自足，
要么初始化推到 `Init()`/`Start()`。

**验证**：**本轮没跑成编译/回归** —— 用户开着 Unity（MainMenu 场景），batchmode 报"另一个 Unity 实例打开了此项目"。
改的是两处字段判断 + 一个 Start，编辑器自动重编译。需要时让用户关编辑器再补跑。
